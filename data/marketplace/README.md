# MarketMind marketplace seed data

Synthetic Indian B2B marketplace CSVs used by `POST /marketplace/demo`.

| File | Entity |
|------|--------|
| `categories.csv` | Product categories (parent + leaf) |
| `suppliers.csv` | Suppliers with ratings & response times |
| `buyers.csv` | Buyer companies by industry |
| `products.csv` | Products linked to suppliers & categories |
| `leads.csv` | Buyer enquiries / leads |
| `orders.csv` | Marketplace orders |

All names and companies are synthetic. No real personal data.
